# Agent 工具清单

思库（Siku）的 Agent 基于 ReAct 循环，通过 **Tool Registry** 动态注册可用工具。默认注册表包含 22 个内置工具，此外还会从技能目录加载若干 `skill_<name>` 动态工具。

> 本文档对应版本：`v1.0.3`

## 调用与审批模型

- **只读工具（`readonly = true`）**：自动放行，无需用户确认。
- **写/执行类工具（`readonly = false`）**：按会话审批策略请求确认，首次调用或每次调用均需用户授权（取决于设置）。
- 所有文件工具受 **工作目录沙箱** 约束；相对路径在沙箱内解析，绝对路径必须位于沙箱内（`working_dir = None` 时开放全盘访问）。

## 文献工具

### `paper_search`

在本地论文图书馆中通过标题、作者、关键词或摘要进行全文搜索。省略 `query` 时按导入时间列出最近的论文；可按收藏夹/标签名过滤。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | ❌ | 搜索词；省略或留空时按导入时间列出最近的论文 |
| `collection` | string | ❌ | 收藏夹名称，只返回该收藏夹内的论文 |
| `tag` | string | ❌ | 标签名称，只返回带该标签的论文 |
| `limit` | integer | ❌ | 最大返回条数，默认 5，最大 50 |
| `offset` | integer | ❌ | 跳过的条数，默认 0 |

### `paper_read`

获取论文的元数据、摘要及分页文本块。默认不返回正文块，可通过 `include_chunks=true` 开启；会自动识别正文结束位置并排除参考文献/附录。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `paper_id` | string | ✅ | 论文 UUID |
| `include_chunks` | boolean | ❌ | 是否返回正文块，默认 `false` |
| `offset` | integer | ❌ | 起始块索引，默认 0 |
| `limit` | integer | ❌ | 返回块数，默认 20，最大 50 |
| `max_chars` | integer | ❌ | 每块最大字符数，默认来自设置 |
| `include_tail` | boolean | ❌ | 是否包含参考文献/附录，默认 `false` |

### `paper_import`

将本地 PDF 文件导入图书馆。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file_path` | string | ✅ | PDF 文件的绝对路径 |

## 笔记工具

### `note_read`

按 UUID 读取单篇笔记，或通过标题/内容全文搜索笔记。超长内容会被截断并标注；搜索结果末尾带总量与翻页提示。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `note_id` | string | ❌ | 笔记 UUID |
| `search` | string | ❌ | 搜索词（与 `note_id` 二选一） |
| `limit` | integer | ❌ | 最大返回条数，默认 10，最大 50 |
| `offset` | integer | ❌ | 跳过的条数，默认 0 |

### `note_write`

创建新笔记或更新已有笔记。更新时会先保存版本历史。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | string | ✅ | 笔记标题 |
| `content` | string | ❌ | Markdown 内容 |
| `note_id` | string | ❌ | 已有笔记 UUID，提供则更新 |
| `paper_id` | string | ❌ | 可选关联的论文 UUID |

## 网络工具

### `web_fetch`

抓取指定 URL 的内容，HTML 会被转换为纯文本。遵守配置的 LLM 代理。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `url` | string | ✅ | 要抓取的 URL |

### `web_search`

通过 DuckDuckGo HTML 端点搜索网络，返回标题、URL 和摘要。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | ✅ | 搜索词 |
| `max_results` | integer | ❌ | 最大返回条数，默认 6，最大 10 |

## 翻译工具

### `translate`

调用翻译服务进行多语言翻译。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | string | ✅ | 待翻译文本 |
| `target_lang` | string | ❌ | 目标语言代码：`zh`、`en`、`ja`、`ko`、`fr`、`de`，默认 `zh` |

## 知识库工具

### `knowledge_query`

在知识库中全文搜索条目，支持按领域过滤。结果带条目 id、截断标记与总量提示（"共 N 条"）。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | ✅ | 搜索词 |
| `domain` | string | ❌ | 领域过滤：`research`、`learning`、`life`、`reading`、`notes` |
| `limit` | integer | ❌ | 最大返回条数，默认 10，最大 50 |
| `offset` | integer | ❌ | 跳过的条数，默认 0 |

### `knowledge_create`

在指定领域创建知识条目。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | string | ✅ | 条目标题 |
| `content` | string | ❌ | Markdown 内容 |
| `domain` | string | ❌ | 领域类型，默认 `notes` |

## 文件工具

文件工具均受工作目录沙箱约束（由 Agent 设置中的工作目录决定）。

### `file_read`

读取文本文件，支持按行偏移分页。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | ✅ | 文件路径 |
| `line_offset` | integer | ❌ | 1-based 起始行；负数从末尾计数，默认 1 |
| `n_lines` | integer | ❌ | 返回最大行数，默认 200，最大 1000 |

### `file_list`

列出工作目录下的文件和子目录。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | ❌ | 目录路径，默认工作目录 |

### `file_write`

创建、覆盖或追加文本文件，自动创建父目录。修改已有文件时应优先使用 `file_edit`（局部替换），避免全量覆盖。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | ✅ | 文件路径 |
| `content` | string | ✅ | 写入内容 |
| `mode` | string | ❌ | `overwrite` 或 `append`，默认 `overwrite` |

### `file_edit`

精确替换文件中唯一出现的子串；如需替换多处，可设置 `replace_all=true`。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | ✅ | 文件路径 |
| `old_string` | string | ✅ | 待替换文本 |
| `new_string` | string | ✅ | 替换后文本 |
| `replace_all` | boolean | ❌ | 是否替换所有匹配，默认 `false` |

### `file_grep`

在工作目录的文本文件中搜索子串（区分大小写，非正则），返回匹配行及行号。结果达到 `max_results` 或扫描文件数达到内部上限（500）时会在输出末尾标注截断，此时应缩小范围重试。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pattern` | string | ✅ | 搜索子串 |
| `path` | string | ❌ | 文件或目录范围 |
| `max_results` | integer | ❌ | 最大匹配行数，默认 50，最大 100 |

### `file_glob`

按 glob 模式列出文件，支持 `*`、`?`、`**`（`**/` 可匹配零层目录，如 `**/*.rs` 同时命中根目录与子目录下的文件）。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pattern` | string | ✅ | glob 模式 |
| `path` | string | ❌ | 可选起始子目录 |

## Shell 与后台任务

### `bash`

执行 shell 命令。默认超时 60 秒，最大 5 分钟；可后台运行（后台任务同样受超时约束）。设置了工作目录（沙箱）时，命令默认在工作目录下执行；否则继承进程启动目录。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `command` | string | ✅ | 要执行的命令 |
| `cwd` | string | ❌ | 相对工作目录的工作目录，默认为工作目录本身 |
| `timeout_ms` | integer | ❌ | 超时毫秒，默认 60000，最大 300000 |
| `run_in_background` | boolean | ❌ | 是否后台运行，默认 `false` |
| `description` | string | ❌ | 后台任务描述（后台运行时必须） |
| `shell` | string | ❌ | 指定 shell：`powershell`、`cmd`、`bash`、`sh` |

### `task_list`

列出由 `bash` 后台运行的任务。

无参数。

### `task_output`

查看指定后台任务的当前输出。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `task_id` | string | ✅ | 任务 ID |

### `task_stop`

停止指定的后台任务。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `task_id` | string | ✅ | 任务 ID |

## 交互与系统工具

### `ask_user`

向用户发起结构化多选题/填空，等待用户回复。由引擎直接处理，不会真正执行到 `execute`。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `questions` | array | ✅ | 1-4 个问题，每个包含 `question`、`options` 等字段 |

### `read_media_file`

读取图片文件并用 Agent 配置的视觉（多模态）模型进行分析。仅用于磁盘上的图片文件（对话中直接附加的图片模型已可见）；单文件上限 20MB。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `path` | string | ✅ | 图片文件路径 |
| `prompt` | string | ❌ | 分析提示词，默认“详细描述图片” |

## 技能工具

启动时，Agent 会从技能目录扫描所有 `.md` 技能文件，并为每个技能注册一个名为 `skill_<name>` 的动态工具。

| 属性 | 说明 |
|------|------|
| 工具名 | `skill_<name>`（`name` 为技能文件名） |
| 只读 | ✅ |
| 参数 | `args`（string，可选）：传递给技能的上下文或参数 |
| 行为 | 调用时将技能内容注入对话，作为该领域任务的专用指令 |
