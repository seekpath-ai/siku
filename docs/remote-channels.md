# 远程接入

思库运行期间，可以通过**飞书机器人**或**微信 ClawBot**远程对话：查询文献与笔记、让智能体处理任务，或把本机文件发到手机。

远程会话会出现在主对话列表中，能力和本机对话一致；不同成员按「全部 / 只读」授权。

> 远程接入是 Beta 能力。微信 iLink 协议不是公开稳定规范，可能随平台客户端变化。

## 支持的渠道

| 渠道 | 接入方式 | 适用场景 |
|---|---|---|
| 飞书 | 企业自建应用 + 长连接 | 私聊、群聊、群文件、进度卡片 |
| 微信 | ClawBot 扫码 + iLink 长轮询 | 私聊、图片/文件、语音转写 |

### 飞书

- 支持多个机器人（跨租户或同租户多应用）
- 私聊和群聊
- 群里默认**仅 @ 响应**
- 支持群信息、群文件查看与导入
- 支持活卡片：工具进度、停止生成、重新生成、思考过程

### 微信

- 需要微信 **8.0.70+**
- 扫码绑定到思库账号，账号下设备共享绑定
- 重复扫码会替换旧绑定
- 当前为单实例，不支持同时登录多个微信
- 支持图片、文件、语音转写结果

## 架构

```text
飞书 / 微信
    │  长连接 / 长轮询（全出站，不需要公网 IP）
    ▼
ChannelManager
    │  启停、单活仲裁、配置热加载
    ▼
Router
    │  去重、防抖、配对、限流、按聊天串行
    ▼
run_agent_turn
    │  复用本机对话智能体与工具
    ▼
回复 / 文件 / 进度
```

相关代码：

```text
src-tauri/src/remote/mod.rs       渠道管理、单活仲裁
src-tauri/src/remote/router.rs    入站路由、批次、账本、回复
src-tauri/src/remote/feishu.rs    飞书适配器
src-tauri/src/remote/weixin.rs    微信 iLink 客户端
src/components/settings/RemoteSettings.tsx  设置页
```

## 配置飞书

1. 在[飞书开放平台](https://open.feishu.cn/app)创建**企业自建应用**。
2. 启用机器人能力。
3. 「事件订阅」选择**使用长连接接收事件**，添加：
   - `im.message.receive_v1`
4. 权限至少包含：
   - `im:message`
   - `im:message:send`
   - `contact:user.base:readonly`（成员昵称）
   - `im:chat`（群名、群信息、群文件）
5. 如需卡片按钮（停止 / 重新生成 / 思考过程），在「事件与回调 → **回调订阅**」中添加：
   - `card.action.trigger`
   - 同样选择长连接接收
6. 在思库「设置 → 远程接入 → 飞书机器人」中填入 App ID / App Secret 并启用。

> 卡片回调需要重新发布应用版本后生效；开发版可先用测试企业与人员验证。

## 配置微信

1. 在思库「设置 → 远程接入 → 微信 ClawBot」点击「扫码连接微信」。
2. 用微信扫码并确认。
3. 如页面提示输入数字，按微信中显示的数字完成验证。
4. 绑定成功后，在微信 ClawBot 里直接发消息。

微信绑定随思库账号同步，其它设备不需要重复扫码。

## 配对与权限

陌生账号第一次发消息时，思库会提示「请在思库设置中确认配对」。

配对键是：

```text
(channel, chat_id, user_id)
```

也就是**按人配对**：

- 私聊默认「全部」权限
- 群成员默认「只读」
- 群内每位成员需要单独确认
- 一个群没有任何已确认成员时，群里的 @ 只会收到配对提示
- 设置页可以随时切换「全部 / 只读」，或删除配对

### 权限差异

| 权限 | 能力 |
|---|---|
| 全部 | 与本机对话一致，包含文件写入、Shell、后台任务等 |
| 只读 | 只能使用只读工具，不能写文件或执行命令 |

远程会话没有审批卡 UI，工具审批会强制走 **Auto**。安全边界主要靠：

- 按人配对
- 只读 / 全部授权
- 群聊仅 @ 响应
- 出站文件总开关

> 给「全部」权限等同于允许对方在思库所在电脑上执行写操作。只给信任的人。

## 消息处理

### 防抖与合并

微信/飞书的一次发送可能拆成多条协议消息，例如文字和图片先后到达。Router 会短暂等待并合并：

| 内容 | 等待窗口 |
|---|---|
| 纯文字 | 约 2 秒 |
| 图片 / 语音等媒体 | 约 3 秒 |
| 文件 | 约 15 秒 |
| 配对等待 | 约 1.5 秒 |

同一聊天串行处理；前一轮未结束时，新消息进入队列，完成后自动继续。

### 启动补收与拆批

应用启动时可能补收到旧消息。Router 会：

- 用入站账本和会话水位线判断消息是否已经处理
- 只对启动补收的旧消息按时间间隔拆批
- 实时消息不会被误拆成多轮

### 去重与重投

远程渠道是至少一次投递，必须按以下方式去重：

- `remote_inbound` / `remote_turns` 账本
- 渠道消息 ID
- 内容指纹（消息 ID 缺失或重投换 ID 时）
- 会话最新用户消息时间水位线

同一轮不会因为重投、接管或重启被重复执行。

## 单活与接管

同一账号下，同一时刻只有一台在线设备持有远程连接：

- 持有设备负责长连接/长轮询
- 其它设备处于 **standby**
- 设置页显示当前接管设备
- 可以点「在本机接管」手动切换

连接租约由 relay 权威维护；续租失败时，客户端进入待机，不会自行抢占。

## 媒体与文件

### 入站

- 图片：进入视觉输入
- 文件：保存到应用数据目录的 `remote_downloads/`，本轮消息携带文件路径和提取文本
- 语音：使用微信服务端转写文本；没有转写结果时提示改用文字
- 文件不会自动导入图书馆；需要时由智能体使用 `paper_import` 或用户手动导入

用户消息中的文件以附件卡展示，不再拼成「（附件《...》）」纯文本。

### 出站

开启「允许远程回传文件」后，智能体可以使用 `send_file_to_user` 把本机文件发到手机。

限制：

- 仅私聊
- 仅「全部」权限成员
- 群聊始终禁止
- 总开关关闭后，工具对所有远程会话隐藏

### 飞书群文件

飞书群聊支持查看群信息和群文件：

- 群文件可以另存为
- PDF 可以导入图书馆
- 入口在对话列表右键菜单，不在对话页头部

微信 iLink 没有群概念，不支持群文件。

## 进度与交互

### 飞书

使用活卡片原地更新：

- 问题摘要与计时
- 工具调用行（阅读文献、检索、联网搜索等）
- 流式正文预览
- 完成 / 失败状态
- 停止生成
- 重新生成
- 思考过程展开/收起

卡片超过长度限制时降级为分段文本。

### 微信

iLink 没有消息编辑端点，因此不做文本刷屏式进度，改用原生 **typing**：

- 回合开始置位
- 5 秒心跳续期
- 回合结束取消

取不到 typing ticket 或发送失败时静默降级，不发送额外的「正在思考」文本。

## 数据与同步

以下内容随思库账号同步：

- 飞书机器人配置
- 微信绑定与游标
- 配对关系与授权
- 入站账本与远程会话

安全说明：

- 同步通道端到端加密
- relay 处理密文和路由所需元数据
- 微信/飞书消息本身会经过对应平台
- 远程渠道不是端到端加密通道

## 已知限制

- 远程**任务触发**与完成主动推送尚未实现；当前以查询和当轮任务为主
- 远程没有审批卡，写操作按 Auto 执行
- 微信 iLink 协议非正式规范，客户端升级可能导致连接失效
- 微信当前只支持单实例
- 微信无法获取群信息/群文件
- 语音依赖微信服务端转写，没有转写时只能改用文字
- 同一账号同时只有一台设备持有连接，其它设备需要待机或手动接管

## 排查

### 发了消息没有回复

1. 看「设置 → 远程接入」状态是否为「已连接」
2. 是否显示「由其它设备接管」；需要时点「在本机接管」
3. 群聊是否 @ 了机器人
4. 是否在待确认配对列表里
5. 查看 `~/.siku/logs/` 中的远程渠道日志

### 重复回复或重复执行

1. 确认只在一台设备上持有连接
2. 检查是否频繁重启或切换接管
3. 保留日志并检查入站账本/水位线是否正常写入

### 图片/文件没有进入本轮

1. 确认发送时间间隔没有超过防抖窗口
2. 文件是否超过渠道大小限制
3. 文件是否成功保存到 `remote_downloads/`
4. 语音是否拿到了转写文本

### 微信扫码失败

1. 确认微信版本 >= 8.0.70
2. 重新扫码，旧绑定会被替换
3. 协议变更时等待思库适配，或改用飞书
