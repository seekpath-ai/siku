# 企业内部文档格式要点

`build_doc.py` template=enterprise 强制执行这些规则，本文档供你（agent）拟稿和自检时参照。适用：公司通知、工作报告、项目方案、规章制度。

## 页面与字体

- A4 普通页边距（上下 2.54cm、左右 3.17cm）
- 正文：宋体 12pt，西文 Calibri，1.5 倍行距，首行缩进 2 字符，两端对齐
- 文档标题：微软雅黑 16pt 加粗居中
- 章节标题：一级 微软雅黑 14pt 加粗、二级 12pt 加粗；**不自动编号**，自拟编号（「一、」「1.」均可）
- 抬头（可选，meta.org）：单位名称雅黑 16pt 加粗居中 + 灰色分隔线；可附文件编号（meta.doc_number）
- 落款（可选，meta.issuer / meta.date）：右对齐，宋体 12pt
- 页码：页脚居中

## 拟稿要点

- 通知：缘由—事项—要求三段式，结尾「特此通知」
- 工作报告：进展用数据说话；问题与下一步计划分开写，避免流水账
- 项目方案：背景与目标 → 方案内容 → 排期 → 风险与应对 → 资源需求
- 规章制度：条款化（第×条），职责、流程、奖惩分明
- 语言比公文灵活，可适当用列表（list 块）；但不用口语和网络用语
