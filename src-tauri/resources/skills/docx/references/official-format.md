# 党政机关公文格式（GB/T 9704-2012 要点）

`build_doc.py` template=official 强制执行这些规则，本文档供你（agent）拟稿和自检时参照。

## 页面与版心

- A4；上边距 37mm、下 35mm、左 28mm、右 26mm
- 正文：仿宋_GB2312 三号（16pt），行距固定值 28.8 磅（每页 22 行），每段首行缩进 2 字符，两端对齐
- 页码：宋体四号，「— N —」页脚居中
- 正文中数字/字母用 Times New Roman

## 版头（红头文件，meta.org 存在时生成）

- 发文机关标志：红色、方正小标宋简体、居中，由发文机关名称 + 「文件」组成（如「××市教育局文件」），字号按字数自动调整
- 发文字号：仿宋三号居中，格式「机关代字〔年份〕序号」——**年份用六角括号〔〕**，序号不编虚位（不写「第」「0」），如「×教发〔2026〕5号」
- 红线：发文字号之下一条与版心等宽的红色分隔线
- 份号/密级/紧急程度（可选，涉密或紧急公文才有）：版心左上角顶格，黑体三号，自上而下排列

## 主体

- 标题：方正小标宋简体二号（22pt），居中；构成为「发文机关 + 事由 + 文种」，如「××市教育局关于加强校园安全管理的通知」
- 主送机关：标题下空一行，顶格，仿宋三号，末尾用全角冒号；多个主送机关分行排列
- 正文层次标题（编号脚本自动添加，不得越级）：
  - 一级「一、」黑体三号
  - 二级「（一）」楷体_GB2312 三号
  - 三级「1.」仿宋三号加粗
  - 四级「（1）」仿宋三号
- 附件说明：正文下空一行，左空二字写「附件：」+ 附件名称；多个附件用阿拉伯数字编号分行
- 发文机关署名与成文日期：正文（或附件说明）下空一行，右对齐、右空四字；日期用阿拉伯数字（「2026年3月5日」，不编虚位）
- 抄送机关（可选）：「抄送：××，××。」四号仿宋，居左

## 拟稿要点（agent 负责）

- 文种选对：通知（批转/告知）、请示（一文一事，结尾「妥否，请批示」）、报告（不得夹带请示事项）、函（平行/不相隶属机关）
- 用语庄重、准确、简明；不用口语和网络用语；称谓统一
- 公文正文不用项目符号列表（脚本会拒绝 list 块），分条用层次标题表达
