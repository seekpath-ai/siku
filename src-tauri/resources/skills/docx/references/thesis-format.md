# 学术论文格式要点

`build_doc.py` template=thesis 强制执行这些规则，本文档供你（agent）拟稿和自检时参照。

## 页面与字体

- A4，普通页边距（上下 2.54cm、左右 3.17cm）
- 正文：宋体小四（12pt），西文/数字 Times New Roman，1.5 倍行距，首行缩进 2 字符，两端对齐
- 页码：页脚居中，五号

## 结构顺序

1. 标题：黑体二号（22pt）居中
2. 作者：宋体小四居中；单位：宋体五号居中，格式「（××大学 ××学院，城市 邮编）」
3. 摘要：「摘  要」黑体小三居中；内容宋体小四，200–400 字为宜，按「目的—方法—结果—结论」写
4. 关键词：「关键词：」黑体加粗 + 3–5 个词，分号分隔
5. 正文章节：脚本自动编号 1 / 1.1 / 1.1.1（黑体三号/四号/小四），不要手写编号；常见结构：引言 → 相关工作 → 方法 → 实验 → 结论
6. 图与表：图题在图下「图1  ×××」、表题在表上「表1  ×××」，宋体五号居中，编号脚本自动完成；正文须先提及再出现（「如图1所示」）
7. 参考文献：「参考文献」黑体三号居中，条目宋体五号，[1] 起自动编号，悬挂缩进

## 参考文献著录（GB/T 7714-2015，agent 负责把条目写对，脚本只排版）

- 期刊：作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
- 专著：作者. 书名[M]. 版次(第1版可省). 出版地: 出版社, 年.
- 会议论文：作者. 题名[C]//论文集名. 出版地: 出版者, 年: 页码.
- 学位论文：作者. 题名[D]. 城市: 学校, 年.
- 电子资源：作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
- 3 名以上作者写前 3 名加「等」（英文文献加 et al.）

## 拟稿要点

- 摘要是一篇文章的缩影：不写背景常识，写清做了什么、怎么做、结果如何
- 图表caption 须自明（不看正文也能懂），单位、样本量等关键信息写全
- 章节标题简洁（≤20字），名词短语式，不用句子
