# 图注与编号约定

## 默认格式

英文：

```text
Figure 1: Caption text
```

中文：

```text
图 1：图注文字
```

## 编号来源

- 扫描目标文件已有图注；
- 取最大编号 + 1；
- `--number` 可覆盖；
- 不自动更新正文引用。

## 图注样式

Word：

- 优先使用内置 `Caption` 样式；
- 没有时使用居中、9pt、斜体。

PPT：

- 图片下方文本框；
- 10pt、居中；
- 自动放在图片下方，空间不足时放在页面底部。

## 插入位置

- Word 默认末尾；`--after` 可指定锚点段落；
- PPT 默认新页；`--slide-index` 可指定已有页；
- 不覆盖原文件。
