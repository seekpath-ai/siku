# 论文示意图规范

## 尺寸

| 用途 | 宽度 |
|---|---:|
| 单栏 | 3.5 in |
| 双栏 | 7.0 in |
| 幻灯片 | 按版面 |

高度按内容；同一组图保持相同高度。

## 节点

- 常规模块：圆角矩形 `round`；
- 数据/张量：普通矩形 `rect`；
- 变量/状态：椭圆 `ellipse`；
- 决策/条件：菱形 `diamond`；
- 纯文字：`none`；
- 节点内文字 7–9pt，最多 3 行；
- 节点之间至少留 0.15in。

## 边

- 主数据流：实线 + 单箭头；
- 可选/辅助：虚线；
- 双向关系：双箭头；
- 标签放在中点上方的白底文字；
- 避免箭头穿过节点文字。

## 分组

- Encoder / Decoder / Training / Inference 用浅色背景 + 虚线边框；
- 组标签放在左上角；
- 组内节点不要压住组标签。

## 字体

- 默认 `DejaVu Sans`；
- SVG 保留文本节点；
- TikZ 使用 `\sffamily`；
- PDF 由 LaTeX 编译，字体嵌入。

## 检查清单

- [ ] 单栏/双栏宽度正确
- [ ] 节点不重叠
- [ ] 箭头不穿文字
- [ ] 组标签不遮挡
- [ ] 字号 ≥ 7pt
- [ ] SVG/TikZ 非空
- [ ] README 写明结构来源
