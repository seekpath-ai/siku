# 论文图表规范

## 尺寸

| 用途 | 宽度 |
|---|---:|
| 单栏 | 3.5 in |
| 双栏 | 7.0 in |
| 幻灯片 | 按版面，不强制 |

高度按内容调整，但同一组多面板应等高。

## 字体

- 正文/坐标轴：7–9 pt；
- 标题：比正文大 1–2 pt；
- 优先 `DejaVu Sans`（跨平台、随 matplotlib 提供）；
- 论文若要求 Times/Helvetica，可在 spec 中改 `font_family`，但必须确认目标机器有该字体；
- PDF 使用 TrueType 嵌入（脚本已设置 `pdf.fonttype=42`）；
- SVG 文字保持文本（`svg.fonttype=none`），便于编辑。

## 颜色

默认色盲友好色板：

```text
#0072B2  #D55E00  #009E73  #CC79A7
#E69F00  #56B4E9  #F0E442  #000000
```

- 不用红绿对立表达唯一区别；
- 灰度打印时仍需可区分（线型/标记辅助）；
- 同一系列在全文中保持同一颜色。

## 矢量与位图

- `figure.pdf` / `figure.svg`：最终稿；
- `preview.png`：只用于预览；
- 照片、复杂热力图可保留位图，但坐标轴和文字仍应是矢量；
- 不要用截图代替矢量导出。

## 可编辑性

- PDF：字体未转曲时可编辑文字；
- SVG：文字默认为文本节点，可在 Illustrator/Inkscape 中编辑；
- 真正可维护的是 `spec.json` + `render.py`；
- 交付时说明字体和编辑工具。
