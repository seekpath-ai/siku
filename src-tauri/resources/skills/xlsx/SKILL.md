# Excel 制作技能

用 `scripts/build_sheet.py` 从 JSON 生成 .xlsx。**不要**自己用 openpyxl 从零写排版代码——排版规范已固化在脚本里，绕过它就放弃了质量保障。

## 运行环境（先读）

技能内容末尾附有「运行环境」块，两种状态：

- **已就绪**：块里给出隔离环境的 Python 解释器绝对路径。下文所有 `python` 命令都换成这个路径执行。**禁止**使用系统 python3/python，**禁止**用 pip 往系统环境安装任何包。
- **未就绪**：调用 `skill_env_setup` 工具自动安装（Miniconda + 依赖，不改动用户系统 Python，首次约需 3-10 分钟），装完用工具返回的解释器路径继续。安装失败或被拒绝时，告知用户也可在「插件 → 技能详情」里手动安装。

## 工作流程

### 1. 确认表格类型与数据来源（必须先问，禁止猜测）

**用户没有明确说明表格类型时，必须先调用 AskUserQuestion 工具询问，等用户选择后再继续。不要根据上下文自行推断，不要用默认值直接开工。**

只有用户消息里已经明确写出（如「做个登记台账」「统计一下按月汇总」「整理成报表」）才可跳过类型提问。「帮我做个表格」「把这些数据放 Excel 里」这类说法**不算**明确，必须问。

用 AskUserQuestion 询问**表格类型**：

- `report` 数据报表（大标题 + 样式化表头 + 冻结首行 + 自动筛选 + 斑马纹，适合向上汇报、对外提供）
- `ledger` 登记台账（无大标题、简洁表头、逐行登记用，适合日常记录维护）
- `analysis` 统计分析（报表样式 + 合计/均值等公式行 + 可选柱状/折线/饼图，适合数据分析汇总）

同时确认**数据来源**：数据是用户已提供（对话里、文件里）还是需要你去收集整理。数据不全时先凑齐数据再开工，不要编造数据填表。

### 2. 整理数据

- 内容归你：字段设计、数据清洗、归类汇总；排版归脚本
- 数值列在 JSON 里用数字（不带千分位逗号），日期用 `YYYY-MM-DD` 字符串，脚本会自动设置单元格格式
- 字段（列）设计遵循 `references/conventions.md`：一列一个含义、单位写进表头、文本左对齐数字右对齐由脚本按类型自动处理

### 3. 写 JSON 文件

按 `scripts/build_sheet.py --schema` 输出的契约写 `<工作目录>/sheet.json`。支持多工作表（sheets 数组）。

- 统计分析的合计行：在 sheet 的 `summary` 里按**表头名**指定聚合方式（sum/average/max/min/count），脚本自动生成公式
- 图表：sheet 的 `chart` 指定 bar/line/pie，类目列与系列列都按表头名引用；饼图仅单系列
- 单元格值可以是以 `=` 开头的公式字符串（脚本做安全校验后原样写入），但优先用 `summary` 而不是手写公式

### 4. 生成

```bash
<运行环境块给出的 Python 解释器> scripts/build_sheet.py sheet.json
```

脚本会**校验并拒绝**违反规范的内容（表头重复、行列超限、非法公式、图表引用不存在的列），报错信息会告诉你怎么改；修正后重跑。生成成功输出 .xlsx 的绝对路径。

### 5. 视觉自检（有 LibreOffice 时必做）

```bash
<运行环境块给出的 Python 解释器> scripts/render_preview.py <产出.xlsx>
```

它把每个工作表渲染成 PNG（依赖 soffice + pypdfium2）。用 read_media_file **逐页查看**，检查：

- 列宽是否合适（有没有文字被截断成 ###、过窄/过宽）
- 表头样式、冻结行、合计行是否正常
- 图表位置与数据是否正确

发现问题 → 修改 sheet.json → 重新生成 → 重新自检，最多迭代 2 轮。没有 soffice 时跳过并告知用户「未做视觉自检，建议打开文件检查排版」。

### 6. 交付

把 .xlsx 的完整路径告诉用户，附一句话说明（类型、工作表数量、行数、是否通过视觉自检）。

## 原则

- **数据归你，格式归脚本**。不要在 JSON 里传自定义字体/颜色/列宽（脚本会拒绝）
- 数字就是数字——不要在数值里混单位、逗号、百分号文本；单位写进表头（如「金额（元）」）
- 一行一条记录，不用合并单元格表达层级（脚本不支持也不该需要）
- 用户提供的数据优先，缺失就问，不要编造
