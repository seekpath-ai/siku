# Excel 排版与数据规范

`build_sheet.py` 强制执行这些规则，本文档供你（agent）设计字段和自检时参照。

## 三个类型的差异

| | report 数据报表 | ledger 登记台账 | analysis 统计分析 |
|---|---|---|---|
| 大标题行 | 有（合并居中，16pt） | 无 | 有 |
| 斑马纹 | 有 | 有 | 有 |
| 冻结首行 | 有 | 有 | 有 |
| 自动筛选 | 有 | 有 | 有 |
| 合计/公式行 | 无 | 无 | 可选（summary） |
| 图表 | 无 | 无 | 可选（chart） |

报表/台账用蓝色系表头，分析用绿色系表头——脚本固化，不可改。

## 字段（列）设计——agent 的核心工作

- **一列一个含义**：不要把「姓名-电话」塞一列；也不要为了好看做二级表头（脚本不支持合并表头）
- **单位写进表头**：「金额（元）」「重量（kg）」「日期」，单元格里只放纯值
- **顺序按阅读逻辑**：标识列（名称/编号）在前，数值列居中，备注类放最后
- 列数 ≤30、单表行数 ≤10000、工作表 ≤10 个（脚本强制）

## 数据值规范（脚本强制/自动处理）

- 数值用 JSON 数字（`1234.5`），**不要**写「1,234.5元」这种带逗号单位的文本——数字格式（千分位、小数位）脚本按值自动设置
- 日期用 `YYYY-MM-DD` 字符串，脚本转成真正的日期单元格；`YYYY-MM` 保持文本
- 空值用 `null`，不要写「无」「-」占位（除非业务上「无」本身就是数据）
- 布尔值直接 `true/false`，显示为 是/否
- 单元格公式：以 `=` 开头的字符串原样写入（脚本做字符白名单校验）；但合计优先用 `summary`，占比优先在数据阶段算好

## 对齐与格式（脚本自动）

- 文本左对齐、数字/日期右对齐、表头居中
- 数字自动千分位；小数按最大值的小数位统一（最多 2 位，整数列不带小数点）
- 列宽按内容自动计算（中文按 2 字符宽），8–40 之间
- 合计行：加粗 + 上框双线，公式引用本列数据区

## 图表（仅 analysis）

- bar 柱状（对比）、line 折线（趋势）、pie 饼图（构成，仅单系列）
- 类目列选文本/日期列，系列列选数值列；系列 ≤4
- 图表放在数据区右侧，不遮挡数据
- 图表标题写清「指标 + 维度」，如「销售额按月分布」
